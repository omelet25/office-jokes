A tiny self-contained Python program that writes one line — a joke about office life — to `/output/entry.txt`. The joke: our printer only jams when the document actually matters, which makes it the most honest performance review in the building. Standard library only, no network, byte-identical on every run.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (one line, 124 characters, UTF-8).
